# Development Environment Setup

## Tools Used
- Visual Studio Code
- Microsoft C/C++ Extension
- MinGW-w64 GCC Compiler

## Setup and Verification
1. Installed Visual Studio Code and the C/C++ extension.
2. Installed and configured MinGW-w64.
3. Verified GCC using `gcc --version`.
4. Created the `hello.c` source file.
5. Initially encountered a file-location issue during compilation because the terminal was in the wrong directory.
6. Resolved the issue by navigating to the Downloads folder using `cd Downloads`.
7. Successfully compiled the program using `gcc hello.c -o hello`.
